### 项目介绍

CoverHub 是基于 uni-app + Vue3 搭建的微信红包封面精选小程序。当前阶段保留首页、分类页和个人中心页等原有页面结构，并提供**封面浏览、封面预览、封面领取、分享好友、联系客服**等基础能力。开发数据与图片均来自项目内的本地 Mock 数据源。

### 项目技术栈

**1.Vue3**

**2.Uniapp**

**3.Ajax**

**4.unicloud**
